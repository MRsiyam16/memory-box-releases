# memory-box releases

memory-box is a desktop app for saving and recalling durable work memory.
This repo holds the Windows release binaries only.

## Download

Download the latest `memory-box-setup.exe` from [Releases](../../releases).

Windows only for now.

## Windows warning

Windows may show "Windows protected your PC" because the app is not code-signed yet.
Click **More info** → **Run anyway**.
